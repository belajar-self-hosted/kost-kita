# Arsip Dokumen Awal

File di folder ini adalah salinan sumber sebelum konsolidasi. Isi awal dipertahankan dan banner status ditambahkan di awal setiap file:

- instruksi-v1.md — sumber awal berisi arahan agent dan kebutuhan rinci.
- prd-v1.md — PRD awal, termasuk ringkasan dan sketsa arsitektur/data.

Snapshot disimpan untuk pelacakan asal konten. Statusnya historis dan non-normatif: jika ada perbedaan, gunakan dokumen aktif yang ditautkan di [indeks](../README.md). Jangan menyalin aturan dari snapshot tanpa memeriksa dokumen pemilik topik dan keputusan terbuka.

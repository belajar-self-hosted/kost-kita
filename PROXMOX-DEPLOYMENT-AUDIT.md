# Audit deployment Proxmox dan LXC

Tanggal: 3 November 2026 (Asia/Jakarta). **Snapshot historis:** temuan ini menggambarkan commit audit, bukan status remediasi saat ini. Tautan bukti ber-anchor menuju commit tersebut; lihat [rencana remediasi](REMEDIATION-PLAN.md) untuk status terbaru. Audit ini menggunakan repository pada `9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a`, dokumentasi dan hasil `git ls-remote`. Tidak ada akses Proxmox, host LXC, inventaris runner GitHub, gateway, atau konfigurasi Cloudflare yang tersedia dalam sesi ini. Tidak ada perubahan produksi atau deployment. Dengan demikian nilai target berikut adalah klaim dokumentasi/konfigurasi, bukan identitas atau keadaan aktual yang telah diverifikasi.

## Pembaruan remediation lokal

Implementasi lokal kini menolak deployment jika hostname/IP, tipe LXC, runner name, target Compose, persistent volume, env-file permissions, image SHA atau minimum free disk/inodes tidak cocok. Runner label saja tetap tidak membuktikan PVE node atau CT ID `10026`; tidak ada shell PVE/LXC untuk menguji identitas, resource, services, DB, scheduler, atau SHA aktif. Gateway Cloudflare/Tunnel/Traefik dan backup/restore juga masih belum dapat diverifikasi. Branch berisi perubahan belum didorong; workflow legacy remote masih perlu dimitigasi dan protection GitHub disiapkan sebelum deployment apa pun.

## Build, deployment dan keselamatan

Source disinkronkan in-place ke `/opt/kostkita/src`, kemudian Compose build image lokal; Compose mengonfigurasi app dari image, bukan source bind mount; runtime aktual belum diverifikasi. Composer `--no-dev`, `npm ci`, Vite build, dan validasi platform tercantum di [Dockerfile:47](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/Dockerfile#L47); `.dockerignore` mengecualikan env dan data. Manifest Vite diintegrasikan melalui [resources/views/app.blade.php:13](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/resources/views/app.blade.php#L13) dan [vite.config.ts:19](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/vite.config.ts#L19), tetapi asset hasil build dan HTTP belum diperiksa. Tag base yang mutable dan `--pull` mengurangi reproducibility.

Aktivasi `docker compose up -d --remove-orphans` mengganti service secara bertahap tanpa switch atomik; app, web dan scheduler bisa berbeda versi selama transisi atau setelah kegagalan. Migrasi dipaksa sebelum aktivasi ketika kode lama mungkin masih berjalan ([deploy.yml:70](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/.github/workflows/deploy.yml#L70)). Tidak ada bukti backup yang dapat dipulihkan, pemeriksaan kompatibilitas schema, retensi image versi sebelumnya, release SHA, atau rollback. Migrasi [000022:28](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/database/migrations/2026_11_03_000022_allow_cancelled_draft_deposit_settlements.php#L28) secara eksplisit menolak `down` saat riwayat tertentu ada: jangan jalankan `migrate:rollback` otomatis. Keselamatan rollback kode tetap bergantung pada kompatibilitas schema dan data.

Env produksi berada di luar build context, tetapi `.env` lama di source dipertahankan oleh rsync dan dapat override env eksternal untuk app/scheduler. Pemeriksaan file workflow hanya memeriksa keberadaan, bukan mode atau nilai efektif. Entrypoint melakukan rekursif `chown`/`chmod` pada storage dan cache setiap start ([entrypoint:4](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/docker/entrypoint.sh#L4)); durasi, ownership dan dampak pada storage bersama belum terukur. Tidak ada cache Laravel atau reload worker eksplisit dalam deploy; image baru memiliki cache per container tetapi cache bersama/storage dan proses aktual harus diperiksa. Compose mendefinisikan scheduler `schedule:work` dengan tiga tugas ([routes/console.php:11](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/routes/console.php#L11)), tetapi pipeline tidak memverifikasi proses atau hasilnya. Queue default database ([config/queue.php:16](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/config/queue.php#L16)); kebutuhan worker dan job produksi harus dibuktikan sebelum menambahkan worker.

Resource aktual, ruang disk, memori, swap, batas CPU, durasi build dan beban request tidak tersedia. Build paralel pada host yang juga melayani produksi dapat menyebabkan resource exhaustion; risiko dan ambang batas harus diukur pada target. Image prune berjalan global bahkan saat gagal dan tidak menjamin image rollback tetap tersedia.

## Health dan ingress

Laravel `/up` didaftarkan di [bootstrap/app.php:17](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/bootstrap/app.php#L17), nginx meneruskannya ke PHP, dan pipeline menguji `/up` serta menjalankan `migrate:status`. Ini belum membuktikan expected SHA/image app-web yang sama, migrasi seluruhnya selesai, aset, kesiapan scheduler/queue, log, maupun jalur publik. IP dan port health hardcoded tetapi Compose dapat mengubah bind dengan env. Fallback localhost tidak membuktikan koneksi gateway ke IP target. Tidak ada bukti pemeriksaan end-to-end atau status service yang sedang berjalan.

Laravel mempercayai `192.168.0.80` sebagai proxy ([bootstrap/app.php:21](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/bootstrap/app.php#L21)), sedangkan nginx meneruskan FastCGI dan forwarded headers ([default.conf:38](https://github.com/belajar-self-hosted/kost-kita/blob/9b4fa27a0126254cdfe3ba41bf2d5403520f0b8a/docker/nginx/default.conf#L38)); identitas `REMOTE_ADDR`, chain proxy, HTTPS, host dan IP klien harus diuji end-to-end sebelum menyimpulkan trusted proxy benar atau salah. Jangan mengubah aturan proxy atau ingress berdasarkan asumsi.

## Bukti yang masih diperlukan

Gunakan akses read-only terotorisasi: cocokkan `pct config 10026` dan inventaris node dengan hostname/IP dari dalam container; cocokkan service runner, UID, workspace dan metadata runner GitHub dengan host tersebut; periksa direktori, owner/mode tanpa menampilkan isi `.env`; catat status dan image ID Compose, deployment SHA yang dapat dibuktikan, versi runtime, kapasitas dan log yang telah disanitasi. Pada gateway dan dashboard Cloudflare cocokkan hostname, route dan target, lalu lakukan smoke test yang aman melalui jalur privat dan publik. Periksa backup/restore, status schema, scheduler, worker bila dibutuhkan, asset, serta kesehatan tanpa mencetak kredensial. Detail urutan dan kriteria penerimaan tersedia di [REMEDIATION-PLAN.md](REMEDIATION-PLAN.md); hasil pemeriksaan live harus dicatat terpisah dengan waktu dan sumber.

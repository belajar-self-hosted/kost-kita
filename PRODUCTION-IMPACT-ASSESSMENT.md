Dampak finansial, downtime yang dapat diterima, kapasitas dan RPO/RTO belum diketahui; tetapkan bersama pemilik berdasarkan hasil inventaris. Compose activation tetap bukan atomic cutover; script mencoba rollback app/web/scheduler ke image lokal sebelumnya di atas konfigurasi Compose kandidat bila verifikasi gagal. Itu rollback image-only dan tidak memulihkan perubahan konfigurasi Compose. Database/volume tidak diubah atau di-prune; pemulihan belum diuji pada Docker LXC dan rehearsal tetap dibutuhkan. Migrasi pending selalu menghentikan deployment; `migrate:status` bukan checksum/schema verifier dan migration `000022` pernah berubah di riwayat repository. Tidak ada migrasi otomatis sampai schema, kompatibilitas, backup/restore dan izin terpisah terbukti. Kondisi Inertia SSR dan dua advisory npm low juga memerlukan penilaian sebelum go-live.
